About This Demo

This application is a minimal but realistic Task Manager built with Jakarta Server Faces (JSF) 4.0 and the PrimeFaces 14 component library running on Jakarta EE 10.

The key point: not a single line of hand-written JavaScript exists in this project. Every interactive behaviour — AJAX partial rendering, modal dialogs, sortable/filterable tables, date pickers, charts — is expressed purely in Java and Facelets XHTML.

Technology Stack

Component Library PrimeFaces 14 Rich widgets: DataTable, Dialog, Chart, DatePicker…

How JSF Avoids Hand-Written JS
JSF maintains a server-side UI component tree. Each p:dataTable, p:dialog, or p:chart tag is backed by a Java class that renders itself to HTML+JS. The developer only writes Java beans and XHTML declarations.
PrimeFaces uses the JSF AJAX API to submit partial forms and update named component regions (update="tableId"). The framework generates and manages all XMLHttpRequest calls.
p:chart serialises a Java model object (BarChartModel, PieChartModel, …) to Chart.js–compatible JSON on the server. The developer configures datasets and colours in Java; no new Chart(ctx, …) call is ever written.
